# Task-4-function_for_reusable_datatask
Task 4: Functions for Reusable Data Tasks

Project Description

This project demonstrates reusable Python functions for calculations, data transformation, and basic statistical operations.

Objective

To understand how Python functions improve code organization, reusability, and readability.

Tools Used

- Python
- Jupyter Notebook / Google Colab
- GitHub

Programs Included

1. Calculate Mean – Calculates the average of a list of numbers.
2. Find Maximum – Finds the largest number in a list.
3. Find Minimum – Finds the smallest number in a list.
4. Calculate Percentage – Calculates percentage from obtained and total marks.
5. Convert Names to Uppercase – Converts student names into uppercase.

Python Concepts Used

- Function definition using "def"
- Function parameters and arguments
- Return values using "return"
- Built-in functions such as "sum()", "max()", and "min()"
- List operations and data transformation

Sample Output

- Mean: 80.0
- Maximum: 100
- Minimum: 25
- Percentage: 85.0%
- Uppercase Names: "['RAVI', 'SITA', 'RAM']"

Conclusion

This task helped me understand how to create and reuse Python functions to perform calculations and transform data efficiently.
